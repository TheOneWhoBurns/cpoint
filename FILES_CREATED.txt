DEPLOYMENT FLOW
================================================================================

1. Read Documentation (30 minutes)
   ├─ Start: DEPLOYMENT_README.md
   ├─ Then: DEPLOYMENT_AWS_SCALE_ZERO.md (detailed)
   └─ Keep: DEPLOYMENT_CHECKLIST.md nearby

2. Configure Terraform (5 minutes)
   ├─ Copy: terraform.tfvars.example → terraform.tfvars
   ├─ Edit: terraform.tfvars with your domain, passwords
   └─ Run: terraform/setup-validate.sh (validate environment)

3. Deploy Infrastructure (30 minutes)
   ├─ Run: terraform/package-lambda.sh
   ├─ Run: terraform init
   ├─ Run: terraform plan
   ├─ Run: terraform apply
   └─ Save: outputs (elastic IP, Lambda URL, ASG name)

4. Deploy CloudFlare Worker (15 minutes)
   ├─ Edit: cloudflare/worker.js (add Lambda URL)
   ├─ Update: cloudflare/wrangler.toml (add account ID)
   ├─ Run: wrangler deploy
   └─ Configure: CloudFlare routes in dashboard

5. Configure DNS (24 hours)
   ├─ Option A: Update Namecheap nameservers to CloudFlare
   └─ Option B: Update Route 53 A records with Elastic IP

6. Initial Boot (10 minutes)
   ├─ Scale up ASG: desired capacity = 1
   ├─ Wait: 5 minutes for instance boot
   └─ Verify: Services running (SSH optional)

7. Test Scale-to-Zero (10 minutes)
   ├─ Scale down: desired capacity = 0
   ├─ Verify: "Server Waking Up" message appears
   ├─ Wait: 2-3 minutes for auto scale-up
   └─ Verify: Applications responsive again

Total Time: 2 hours active + 24 hours DNS propagation

PASSWORDS & SECRETS
================================================================================

These need to be set in terraform.tfvars (not in any files):

  db_password
    - PostgreSQL password (minimum 16 characters)
    - Used by rental app and Odoo
    - Store securely, never commit to git

  odoo_master_password
    - Odoo admin password (minimum 16 characters)
    - Used to create Odoo database
    - Store securely, never commit to git

AWS Credentials:
  - Configured via "aws configure"
  - Stored locally in ~/.aws/credentials (Linux/Mac) or %USERPROFILE%\.aws\ (Windows)
  - Never store in repository

CloudFlare API Token:
  - Used by "wrangler login"
  - Stored locally in ~/.wrangler/config.toml
  - Never store in repository

SSH Key:
  - AWS auto-generates EC2 key pair
  - Download and store securely
  - Use for: ssh -i your-key.pem ec2-user@<IP>

QUICK REFERENCE - IMPORTANT COMMANDS
================================================================================

Validate Environment:
  $ cd terraform && chmod +x setup-validate.sh && ./setup-validate.sh

Package Lambda:
  $ chmod +x package-lambda.sh && ./package-lambda.sh

Deploy Infrastructure:
  $ terraform init && terraform plan && terraform apply

Deploy Worker:
  $ cd ../cloudflare && wrangler deploy

Scale Up (First Boot):
  $ aws autoscaling set-desired-capacity --auto-scaling-group-name rental-odoo-asg --desired-capacity 1

Scale Down (Test):
  $ aws autoscaling set-desired-capacity --auto-scaling-group-name rental-odoo-asg --desired-capacity 0

Get Instance IP:
  $ aws ec2 describe-instances --filters 'Name=tag:Name,Values=rental-odoo-server' --query 'Reservations[].Instances[].PublicIpAddress' --output text

SSH to Instance:
  $ ssh -i your-key.pem ec2-user@<IP>

Check Services:
  $ sudo systemctl status postgresql-16 rental-app odoo nginx

List Backups:
  $ aws s3 ls s3://rental-odoo-backups-<suffix>/daily/
